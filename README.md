## Overview
This is a calculator with standard number buttons and operators with four extra buttons. Those take one number to the power of another, the natural logarithm, the sine function, and the cosine function.

## Current Status
Working:
- Numbers with both the mouse and keyboard.
- Functionality of the operators.

Still in progress:

## How to Run
Built with Processing.
Processing version: 4.0.1

There is a main Calculator.pde file and a class Button.pde file.

## Controls
Mouse:
You can use the mouse to click on the buttons.

Keyboard:
All the numbers and the decimal button work at this moment.

## Project Files
The main sketch is the Calculator and is has a Button class tab.
